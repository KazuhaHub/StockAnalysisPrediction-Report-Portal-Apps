## 二、SIG-002 对照实测（2018-01-01 起点，上市满 3 年）

| 指标 | 全池 | 过滤池 | 差值 |
|:---|---:|---:|---:|
| 样本只数 | 1,989 | **1,054** | −935（**−47%**） |
| 同日横截面 Δ(pct) | +2.181 | +2.167 | −0.014（**−0.6%**） |
| 横截面 t | +43.68 | +43.75 | +0.07 |
| 训练 / 测试段 Δ | +1.915 / +2.399 | +1.951 / +2.345 | +0.036 / −0.054 |
| **组合年化(pct)** | **+5.06** | **+4.14** | **−0.92（−18%）** |
| 判定 | PROMOTE | PROMOTE | 一致 |

**结论要拆两半报**：核心命题（高波动 → 后续绝对波动更大）不是次新股驱动的，
剔掉 47% 样本 Δ 只动 0.6%、t 还微升（被剔掉的票噪声更大、稀释了效应）；
但**组合年化掉了 18%**——`vol20>0.45` 在次新股上触发更频繁，池子一换组合构成就变。
横截面 Δ 稳 ≠ 策略收益稳。

一次阴性结果同样是可证伪检验的输出：它只证明「在上市年限这一个维度、
对 SIG-002、在这个起点下，偏差量级 ≤0.6%」，不证明没有偏差。换规则/起点/持有期都要重跑。

## 三、四个反直觉发现

**1. 缺的不是「新股元数据」，是老票。**
515 只整行空缺里 **325 只从 2014-06 库起点就有数据**，包括 `000001 平安银行`、
`600022 山东钢铁`。真实原因是当初 `ss_cache` 迁移带了 1,521 只元信息，
后来补的 515 只只补了 K 线。所以这不是数据能力问题，是一次静默的补全遗漏。

**2. 跨源复权口径不一致，差近 1%/日。**
`000001` 同 203 天：本地库（`stock-server.daily_hfq`）与 akshare hfq
比值 **1.206–1.261**（非恒定，std 0.0132），**逐日收益率最大绝对差 0.00945**。
这足以翻转任何波动率/动量信号。所以 akshare 在这套体系里**只能补元数据**，
行情必须继续走 stock-server。已写进本地库 README 的第 8 条限制。

**3. 扩池的收益取决于一个还没定的口径。**
外部沪深全 A 5,224 只，缺口 **3,188 只**；但只有 **1,285 只（40.3%）**
在 2018 起点已上市满 3 年，近 60% 是 2017 年后上市的次新股。
**不先定「是否默认带上市年限过滤」就扩池，等于往 2018 年横截面灌进约 1,900 只
当年还不存在的票——前视偏差会变大而不是变小。**
所以上一轮写的「补元数据 → 上市年限 → 扩池」顺序要改：先定口径，再扩池。

**4. 幸存者偏差确凿，且库内修不掉。**
`stock_info_sh_delist` + `stock_info_sz_delist` 共 373 只，其中
**284 只在 2014-06 之后退市/暂停上市，本地库一只都没有（0 误入）**，
集中在 2022–2026 年。`doctor` 的独立检查也报「仅 0 只在数据末日前 60 日以上停止交易」，
两边对上了。退市票历史行情可取（`000033` 拿到 186 根），技术上补得进来。

## 四、为什么扩池与退市股入池没执行

技术上都通：stock-server 在线，抽 5 只缺口票（1998/2004/2010/2022/2026 上市）
全部返回完整历史，且同源口径天然一致。不做的理由是**它们不是补数据，是换检验总体**：

1. `n_stocks` 会从 1,989 变到约 5,000，**20 条信号的全部判定基线都要重算**，
   多重检验校正基数也变；`doctor` 会进入「判定前提漂移」状态，需一次性 `test --all`。
2. 284 只退市股补进来后历史收益分布系统性下移，所有 `PROMOTE` 都得重检。
3. 近 60% 的缺口票对当前 2018 口径无效，收益要打 6 折——先定口径才划得来。

**需要你定的一句话**：`test` 的默认口径要不要带上市年限过滤？
- 定「是」：扩池收益最大（2018 有效样本 1,054 → 上界 2,364），随后扩池 + 退市股一次性做；
- 定「否」：扩池应当暂缓，`bias` 继续只作引用时的量级脚注。

另外提醒：`exposure` 仍缺真实持仓、三个上限和自定主线划分，缺省永远 `UNJUDGED`。
