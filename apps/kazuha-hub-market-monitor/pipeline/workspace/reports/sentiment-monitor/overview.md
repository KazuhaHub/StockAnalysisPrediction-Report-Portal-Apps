# 市场情绪每日监控面板 · 交付说明

## 做了什么

把上一轮的市场情绪研究（`reports/market-sentiment/`）落地成一个可每天打开的监控面板，而不是又一份静态报告。

核心区别：**报告回答「怎么判断」，面板回答「今天该不该动」**。因此面板上每个数字都带一个可执行含义，没有形容词。

## 打开方式

```
reports/sentiment-monitor/monitor.html
```

单文件离线，1.0 MB，双击即可，不依赖网络。

## 面板结构

| 区域 | 内容 | 为什么放这里 |
|---|---|---|
| 顶栏 | 数据日 + 新鲜度警告 | 数据没更新时立刻标黄，避免拿旧数据做决策 |
| 当前判读 | 一句话结论 | 30 秒内看完走人 |
| KPI × 4 | 广度、集中度、信号天数、路径偏离 | 四个能单独触发动作的数字 |
| 01 五维分位 | 五条横条 + 5 日/20 日变化 + 每个维度的有效性评级 | 同时给出「读数」和「这个读数值不值得信」 |
| 02 当前组合格 | 广度 × 集中度 4×3 热力图 | 同样广度下，集中度高低的赔率差 4pp，这是全篇最硬的发现 |
| 02 信号进程 | 本轮路径 vs 历史 15 簇中位路径 | 一眼看出「走得不顺」：第 17 日历史中位 +5.90%，实际 −1.51% |
| 03 今日预警 | 4 条规则化预警，按红/黄/绿分级 | 每条都写明触发条件与对应动作 |
| 04 极端读数 | 7 个指标的原始值 + 三年分位 | 分位会钝化，原始值不会（跌停 34 家 vs 分位 93%） |
| 05 近一年轨迹 | 五维 5 日平滑折线 | 看背离：资金结构 90+ 而广度 15，这是当前的核心矛盾 |

## 当前读数（2026-11-13）

- 量能 47 / 广度 15 / 极端 16 / 赚钱效应 27 / **资金结构 88**
- 组合格：**10–20% × 集中度高** → 历史 20 日中位仅 **+1.44%**（135 个交易日）
- 广度极冷信号（above_ma250 < 15%）自 **2026-10-22** 起，第 **17** 个交易日，等权组合 **−1.51%**
- 离散度 31pp，历史 83% 分位

**结论**：结构性出清未完成。资金没离场（量能 47%），但也不肯扩散（集中度 88%），此时「跌得多」不等于「便宜」。

## 一个必须说明的口径修正

上一轮报告中写的「2026-10-29 触发、至今 +0.80%」，是按**最冷点**取的口径。
按可复现的规则（above_ma250 连续 < 15% 的簇起点），实际触发日是 **2026-10-22**，至今 **−1.51%**。

面板采用规则口径，因为它是可自动复现的；同时保留了「若以本轮最低点 10-30 计为 +3.50%」的对照说明。
这个差异本身就是结论：**从进入极冷区开始算，到现在是亏的**。

## 每日自动更新

已创建 automation：**周一至周五 23:50**（行情库 23:30 更新之后）自动执行
`analysis/sentiment_daily.py` → 重建面板 → 汇报一句话摘要。

手动更新：
```bash
/opt/daily-tasks/venv/bin/python3 analysis/sentiment_daily.py
cd reports/sentiment-monitor && cp monitor.src.html monitor.html && \
  python3 ~/.workbuddy/skills/html-report/scripts/build_report.py monitor.html
```

## 踩坑记录（复用价值）

1. **echarts visualMap 默认取数据数组的最后一维做映射**。热力图数据是 `[x, y, value, ...]`，
   加了样本数之后，visualMap 会把样本数当数值，导致所有格子颜色相同。必须显式写 `dimension: 2`。
2. **visualMap 默认作用于所有 series**，多层叠加（底色层 + 描边层）时描边层会被染色并盖住下层数字。
   改用 `seriesIndex` 限定，或干脆不叠加描边层，用 data 级 `label` 反白标注当前项。
3. **`build_report.py` 是原地内联**，对同一文件重复运行会叠加污染（内联代码里再内联）。
   正确做法是保留 `xxx.src.html` 作为源，每次 `cp src → 产物` 再构建。
4. **截图验证比读代码可靠**，但 headless Chrome 的窗口高度不够会裁掉图表底部坐标轴标签，
   看起来像渲染 bug，实际是截图问题。分部截图时窗口高度要给足。

## 已知局限

- 条件分布热力图的格子重叠极严重（同一段行情贡献数百个交易日），它描述的是统计分布，不是概率。
- 事件簇只有 15 个且集中在 2015/2016/2018/2024，不做 t 值显著性声明。
- 行情库覆盖 3,300 只左右可交易个股（库内 3,578 只含退市），有幸存者偏差，但等权基准受影响较小。
- 两融数据仅 2024 年起，MSASI 只能复现 3/5 成分（缺北向逐日、缺一致预期快照）。
