# 数据字典 · ~/MarketData

写任何分析之前先读这一页。口径错一次，后面所有结论都要重做。

**规模**：3,486 只 × 9,113,716 根日线，`bars/` 349 MB，覆盖 **2014-06-03 ~ 2026-11-06**。
其中 169 只是已退市股（`status=delisted`）。数据源：`stock-server` 的 `daily_hfq`，**后复权**。

---

## 1. 表结构

`bars/YYYY.parquet`（按年分区，长表，每行一根日线）：

| 列 | 类型 | 含义 | 坑 |
|---|---|---|---|
| `code` | str | 6 位代码，`000001`，不带交易所后缀 | — |
| `date` | str | `YYYY-MM-DD`，字典序＝时间序 | — |
| `open/high/low/close` | float | **后复权**价 | 不是真实成交价 |
| `volume` | float | 成交量，单位「股」，但是**复权口径** | 真实股数 = `volume × factor` |
| `amount` | float | 成交额，**元，真实值**，不受复权影响 | 与 `volume×close` 同量级但不同义 |
| `factor` | float | 累计复权因子 | 真实价 = `close / factor` |
| `tradestatus` | int8 | 现在**全是 1** | **不能用来判断停牌**，见 §3 |

---

## 2. 三个必须记住的口径

### 2.1 后复权，历史永不改写

前复权在每次新除权时重算全部历史，增量更新必然对不齐；后复权只缩放**新数据**，
历史 bar 永不改写——这是「增量只 append」能成立的前提。

**代价**：同一只票的绝对价格会越涨越离谱（茅台 `close` 11146 元），
只能比相对变化，不能当价格用。要真实价自己除 `factor`。

### 2.2 `volume` 是复权股数，不是真实股数

源端把成交量也按因子缩放了。实测：

| | 茅台 2026-11-06 | 平安银行 2026-11-06 |
|---|---|---|
| `volume`（库内值） | 558,551 | 1,202,894 |
| `factor` | 7.671 | 136.36 |
| 真实股数 = 相乘 | **4.28 百万股** | **1.64 亿股** |
| 校验：`amount / 真实价` | 6.20e9 / 1453 = 4.27e6 ✓ | 1.93e9 / 11.81 = 1.63e8 ✓ |

所以：

```python
real_shares = volume * factor          # 真实成交股数
vwap         = amount / real_shares    # 当日真实成交均价
```

**直接拿 `volume` 排流动性、算换手代理，会让长历史票系统性偏低**（茅台被低估 7.7 倍、
平安被低估 136 倍），而且低估幅度随上市年限单调上升——这不是噪声，是会污染排序的偏差。

`amount / volume` 得到的是**后复权价**，不是成交均价。

### 2.3 停牌日「有 bar」，只是零成交

全库 **244,116 行（2.7%）** 是 `volume = 0 / amount = 0`、OHLC 四价完全相等、价格等于前收。
其中 2015 年 81,841 行——那轮停牌潮。

- **停牌 ≠ 缺行**。缺行只有三种原因：未上市、已退市、库里没这只票。
- 停牌行参与截面计算时，收益率恒为 0（正确），但它会被算进「当日有交易的股票数」，
  也会在按 volume 排序时排在最前面。
- **要算「真实交易日」的横截面，先过滤 `volume > 0`。**

## 3. 缺失与空值的语义

| 现象 | 含义 | 怎么办 |
|---|---|---|
| 某票某日没有 bar | 未上市 / 已退市 / 库内无此票 | 查 `meta.list_date`、`meta.status` |
| 有 bar 但 `volume=0` | 停牌，价格延续前收 | 需要流动性就过滤；别把 0 收益当信息 |
| `tradestatus` 全 1 | 源端没提供停牌标记 | 别用，用 `volume` |
| 2014-06-03 之前 | 库起点，没有 | 要更早自己补 |
| 2026-11-06 之后 | 增量还没跑 | `market_data.py update` |

## 4. meta.json 字段

```json
{"name":"平安银行","board":"深主板","list_date":"1991-04-03",
 "sw1":"银行","sw2":null,"sw3":null,"sw_l3_code":null,
 "first":"2014-06-03","last":"2026-11-06","n_bars":3023,
 "status":"delisted","updated":"2026-11-07T09:51:51","meta_source":"akshare@2026-11-07"}
```

| 字段 | 覆盖率 | 用途 |
|---|---|---|
| `name` / `board` | 100% | 沪主板 1,255｜深主板 1,319｜创业板 692｜科创板 220 |
| `list_date` | 100% | **成分前视过滤的唯一依据**（上市满 N 年） |
| `sw1` | 3,316 / 3,486 | 行业中性化；缺的 170 只基本都是退市股 |
| `first` / `last` / `n_bars` | 100% | 与磁盘逐票对账（`check` 查这个） |
| `status` | 169 只 `delisted` | 退市股不再增量，仍可用于历史回测 |

## 5. 已知瑕疵清单

| # | 瑕疵 | 规模 | 状态 | 规避 |
|---|---|---|---|---|
| 1 | **零成交日复权断点**：停牌期间价格凭空跳变（因子没同步股本变动） | 630 只 / 768 行，被抹掉的假收益中位 −0.5%、极端 −75% ~ +705% | **2026-11-08 已修**，清单 `docs/adjbreak_fixed_20261108.csv` | 新数据每年复查约 2–5 例：`python3 fix_adjbreaks.py` |
| 2 | denormal 成交额 `5.877e-39` | 967 行（2026） | 已归零 | `amount > 0` 的过滤现在可信 |
| 3 | 停牌行占比 2.7%，2015 年尤其密集 | 244,116 行 | 结构性，不修 | 横截面先 `volume > 0` |
| 4 | 有成交日的断点：单日 \|收益\|>30% 且 **`factor` 与前一日相同** | 153 行 / 148 只，其中 86 行因子未变 | **修不了**（缺股本数据，无法分辨缩股/拆股与真实复牌） | 当作「读到的收益不可信」：`qsr doctor` 已整只剔除这类票；单票研究先查 `factor` 有没有变 |
| 4b | 真实事件的极端收益：重整复牌、新股首日、北交所 30% | 与 4 混在同一批里，最大 +1975%（002506 2015-08-12，1 拆 3 + 无涨跌停） | 故意不修 | 回测做 winsorize，别按「不合理」删除 |
| 4c | **除权日因子滞后**：源端在除权后仍用旧因子，把未复权价写进后复权序列。2026-11-10 `603596` 10 转 4，库内 −27.96%（= 不复权跌幅），东财后复权应为 +2.21% | 全库扫仅此 1 只 / 1 行（`analysis/scan_bad_bars.py` 用官方涨跌幅仲裁） | **未修，待定**：增量单向，11-10 这根不会自动纠正 | 看 `update` 输出里「新旧衔接跳空 >25%」告警；只吃现金分红的票滞后幅度小（1–3%），这条扫法抓不到 |
| 5 | 幸存者偏差 | 退市股仅 169 只，外部口径约 284 只 | 部分缓解 | 结论里说明「退市覆盖不全」 |
| 6 | 无股本 / 流通股本 | — | 缺数据 | 换手率、市值因子**做不了**，只能用 `amount` 当流动性代理 |
| 7 | 无涨跌停 / ST / 新股首周标记 | — | 缺数据 | 按代码段 + `list_date` 自己推 |
| 8 | 2015 年后上市 1,902 只未补 | B 批 | 待做 | 需把 `start` 后移，历史窗口变浅 |

## 6. 常用配方

```python
import sys; sys.path.insert(0, "/opt/daily-tasks/MarketData")
import market_data as md

px   = md.panel("close", start="2020-01-01")     # 后复权宽表，index=日期
vol  = md.panel("volume", start="2020-01-01")
fac  = md.panel("factor", start="2020-01-01")
amt  = md.panel("amount", start="2020-01-01")

ret = px.pct_change().where(vol > 0)             # 停牌日收益置空，别当 0
real_px  = px / fac                              # 真实价
shares   = vol * fac                             # 真实成交股数
vwap     = amt / shares                          # 真实成交均价
liq      = amt.rolling(20).mean()                # 流动性代理（元）

meta = md.universe()                             # 每票元信息
old  = {c for c, m in meta.items()
        if m.get("list_date") and m["list_date"] <= "2015-01-01"}   # 上市满 10 年
```
